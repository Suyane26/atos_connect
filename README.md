# Atos Connect

App para conectar e organizar o ministério de jovens — notificações de visitas, playlists de louvor por categoria de culto e mural de avisos, com planos de expansão para outros departamentos da igreja.

> O nome é inspirado no livro de Atos dos Apóstolos: um movimento que começa pequeno e se espalha. O projeto nasce no departamento de jovens com a visão de crescer para toda a igreja.

## Sobre o projeto

O **Atos Connect** foi criado para resolver dores reais do dia a dia do ministério:

- Esquecer visitas a cultos de jovens de outras igrejas
- Dificuldade de organizar as músicas já louvadas por tipo de culto
- Falta de um canal centralizado de avisos
- Perder datas importantes como aniversários e conquistas dos jovens

## Funcionalidades

### Em desenvolvimento (MVP)
- [ ] **Mural de avisos** — comunicados do ministério em um só lugar
- [ ] **Perfil do jovem** — cadastro com aniversário e conquistas

### Planejadas
- [ ] **Notificações de visita** — aviso no início da semana sobre cultos de jovens de outras igrejas
- [ ] **Playlists por categoria de culto** — músicas organizadas por tipo (Santa Ceia, Louvor e Adoração, Ministração, Abertura, etc.)
- [ ] Calendário de eventos
- [ ] Escala de equipe (louvor, som, direção)
- [ ] Expansão para outros departamentos (crianças, senhoras, ministério geral)

## Tecnologias

- **Flutter** (Dart) — desenvolvimento mobile multiplataforma
- **Firebase** — banco de dados, autenticação e notificações *(planejado)*

## Como rodar o projeto

```bash
# Clone o repositório
git clone https://github.com/seu-usuario/atos_connect.git

# Entre na pasta do projeto
cd atos_connect

# Instale as dependências
flutter pub get

# Rode o projeto
flutter run
```

## Pré-requisitos

- [Flutter SDK](https://docs.flutter.dev/get-started/install) instalado
- Android Studio ou VS Code com plugin Flutter/Dart
